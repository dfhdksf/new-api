# 鹈鹕测试配置保存

配置保存在当前浏览器的 localStorage 中，不会发送到服务器保存，也不会随应用容器替换而主动删除。

- 当前表单在编辑后自动保存；每个密钥只有勾选“在此浏览器记住密钥”才会保存其内容。
- 在“已保存的配置”中输入名称并点击“保存配置”，可独立保留当前整组站点、多密钥、模型、推理强度、重复次数和并发数；最多保存 20 组。同名保存会更新该组配置。
- 选择已保存的配置并点击“加载配置”即可复用，加载和导入都不会自动发起付费测试。删除操作只删除选中的命名配置。
- “导出配置”下载当前表单为 JSON 文件；“导入配置”恢复该表单，之后可以再次命名保存。只导出已勾选记住的密钥，文件可能包含明文密钥，请妥善保管。导入文件上限为 2 MiB。
- 浏览器按协议、主机名和端口隔离存储，例如 `localhost:5173` 与 `localhost:3000` 各自保存配置。跨地址、浏览器或机器请使用导出、导入迁移。

前端缓存版本更新会保留所有 `new-api:pelican-test:` 数据，包括当前配置、命名配置库和测试历史。存储失败会显示提示；无效的编辑值不会覆盖上一份有效配置，打开页面也不会立即用默认值覆盖无法读取的数据。

清除网站数据、使用无痕窗口或删除浏览器配置仍可能使本地数据消失。需要长期留存时，建议同时导出文件备份；已经被清除且没有备份的密钥无法从应用中恢复。
